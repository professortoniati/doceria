## 📋 Sobre o Projeto

Site institucional da **Delicias da Mary Confeitaria**, localizada no Jardim São Luís em São Paulo/SP. O projeto foi desenvolvido com o objetivo de apresentar a confeitaria de forma profissional, atrativa e acolhedora, facilitando o contato com os clientes e a conversão de visitantes em pedidos.

> *"Os Melhores Doces da Região 😋🍫🥧"*  
> *Feitos Com Muito Amor ❤️*

---

## ✨ Funcionalidades

- 🏠 **Hero Section** — Chamada principal com botões de ação direta
- 🎂 **Cardápio** — Seção de produtos com categorias e filtros interativos
- 💬 **Integração WhatsApp** — Botões de pedido que abrem conversa direta no WhatsApp
- ⭐ **Avaliações** — Depoimentos reais de clientes com nota 5,0
- 📍 **Localização** — Mapa integrado com endereço completo
- 📱 **Formulário de Contato** — Formulário que envia pedido via WhatsApp
- 📸 **Integração Instagram** — Link direto para o perfil @deliciasdamary18
- 🔝 **Botão Voltar ao Topo** — Navegação fluida
- 📲 **Totalmente Responsivo** — Layout adaptado para mobile, tablet e desktop

## 🎨 Design & Tecnologias

Este projeto foi construído com tecnologias 100% frontend, sem dependências de frameworks ou bibliotecas externas:

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura semântica e acessibilidade |
| **CSS3** | Estilização, animações, layout responsivo (Flexbox/Grid) |
| **JavaScript Vanilla** | Interatividade, IntersectionObserver, Lazy Loading |

### Recursos de Performance
- ⚡ **Lazy Loading** de imagens com `IntersectionObserver`
- 🎞️ **Scroll Reveal** com animações suaves
- 📊 **Counter Animation** para estatísticas
- 🔄 **Parallax** sutil no Hero
- 🎯 **Staggered Animations** em cards

## 🚀 Como Executar Localmente

Como é um projeto 100% estático, basta abrir o arquivo `index.html` no navegador:

### Opção 1 — Abrir diretamente
```bash
# Clique duplo no arquivo index.html
# Ou arraste-o para o navegador
```

### Opção 2 — Via extensão Live Server (VS Code)
1. Instale a extensão **Live Server** no VS Code
2. Clique com o botão direito em `index.html`
3. Selecione **"Open with Live Server"**

### Opção 3 — Via Python (sem instalação de extensão)
```bash
# Python 3
python -m http.server 8080
# Acesse: http://localhost:8080
```
